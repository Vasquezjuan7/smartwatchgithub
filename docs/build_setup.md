# Build and Environment Setup

Guia de configuracion de dependencias y variables de entorno para compilar Wear OS App.

## Variables necesarias en local.properties
- github.clientId: Client ID de la aplicacion OAuth de GitHub (Device Flow).
- supabase.url: URL del proyecto Supabase para la Edge Function de IA.
- supabase.key: Clave publica anónima (anon key) de Supabase.
