# Modo Demo Offline para Exposiciones

Para presentaciones academicas o ferias tecnicas donde la conexion Wi-Fi puede ser inestable:
- Permite probar el 100% de la aplicacion sin conexion a GitHub ni a Supabase.
- Simula latencias reales de red (\delay(1400)\) y calculo de IA.
- Contiene Pull Requests de ejemplo con diferentes grados de riesgo (Bajo, Medio, Alto).
- Permite ejecutar la simulacion completa de merge y confirmacion haptica sin tocar repositorios reales.
