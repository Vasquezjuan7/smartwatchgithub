# Gestor Colaborativo de Despliegues (Smartwatch)

Herramienta DevOps de bolsillo para Wear OS que permite aprobar o rechazar Pull Requests de GitHub directamente desde el smartwatch con ayuda de IA.


## Caracteristicas
- Wear OS Compose Material 3
- Integracion con GitHub API
- Backend en Node.js
- Feedback Haptico
