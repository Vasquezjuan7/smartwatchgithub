# Changelog

Todos los cambios notables en este proyecto se documentan en este archivo.

## [1.0.0] - 2026-11-18
### Added
- Autenticacion directa con GitHub mediante OAuth Device Flow (RFC 8628).
- Cliente nativo Wear OS con Jetpack Compose Material 3.
- Tema visual Aurora con fondos dinamicos orbitales y Glassmorphism para pantallas OLED.
- Boton de confirmacion Hold-to-Confirm con animacion radial y respuesta haptica.
- Resumenes de PR y analisis de riesgo automatizados con Google Gemini a traves de Supabase Edge Functions.
- Notificaciones en segundo plano con WorkManager (revision cada 15 min) y vibracion en muñeca.
- Modo demo offline con dataset simulado para presentaciones.
- Suite de pruebas unitarias automatizadas con JUnit.
- Pipeline de Integracion Continua (CI) con GitHub Actions.
