# Guia de Contribucion

Agradecemos tus contribuciones al Gestor Colaborativo de Despliegues para Wear OS.

## Formato de Commits (Conventional Commits)
Utilizamos el estandar Conventional Commits para mantener un changelog automatico y legible:
- \eat(scope): ...\ para nuevas caracteristicas.
- \ix(scope): ...\ para correcciones de bugs.
- \docs(scope): ...\ para actualizaciones en documentacion.
- \style(scope): ...\ para cambios de formato visual o diseno.
- \efactor(scope): ...\ para refactorizacion de codigo.
- \	est(scope): ...\ para creacion o mejora de pruebas.
- \ci(scope): ...\ para configuracion de pipelines.
